# Support

Use GitHub Issues for reproducible bugs and focused feature requests. Include the affected route,
browser or runtime, expected behavior, actual behavior, and a minimal reproduction where possible.

Questions about deploying or operating the separate Pryv API/TEE backend belong in that service's
support channel. This repository only covers the web and Expo clients.

For vulnerabilities or sensitive logs, follow [SECURITY.md](SECURITY.md) instead of opening a public
issue.
